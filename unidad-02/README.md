# Unidad 02 - Instalación, configuración y uso de entornos de desarrollo

## Descripción
Preparar un entorno de desarrollo reproducible y reconocer sus herramientas.

## Objetivos
- Comprender los conceptos fundamentales de esta unidad.
- Identificar técnicas y herramientas aplicables al desarrollo de software.
- Documentar actividades y ejercicios de la asignatura.

## Contenidos
1. JDK, JRE y JVM: responsabilidades.
2. Instalación y comprobación de Java y de IntelliJ IDEA.
3. Estructura de proyectos, carpetas y archivos.
4. SDK del proyecto y configuración de ejecución.
5. Terminal integrada, compilación y ejecución.

## Actividad de la unidad
Configurar un proyecto Java e iniciar un programa HolaMundo.

## Conceptos clave
- Relación entre JDK, compilador y JVM.
- Ruta del proyecto y directorio de trabajo.
- Diferencias entre ejecutar desde el IDE y desde la terminal.
