# Unidad 04 - Elaboración de diagramas de clases

## Descripción
Modelar la estructura estática de una aplicación mediante diagramas UML de clases.

## Objetivos
- Comprender los conceptos fundamentales de esta unidad.
- Identificar técnicas y herramientas aplicables al desarrollo de software.
- Documentar actividades y ejercicios de la asignatura.

## Contenidos
1. Clases, atributos, operaciones y visibilidad.
2. Asociaciones y multiplicidades.
3. Agregación y composición.
4. Generalización e implementación de interfaces.
5. Correspondencia entre modelos UML y código Java.

## Actividad de la unidad
Diseñar un diagrama de clases para un sistema de biblioteca.
