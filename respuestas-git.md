¿Qué diferencia existe entre git add y git commit?
git add añade los archivos para que s garden en el siguiente commit, mientras que git commit los guarda.

¿Qué hace git push y por qué puede ser rechazado?
git push se usa para subir los cambios realizados a la nube, puede ser rechazado por una incompatibilidad entre los commits realizados.

¿En qué se diferencian git fetch y git pull?
git fetch descarga los archivos guardados en la nube para guardarlos de forma local, mientra que git pull los descarga y los mezcla con los ya existentes.

¿Qué significa origin/main?
Es la rama principal de GitHub

¿Qué muestra git status antes y después de git add?
Antes de un git add se muestran los archivos modificados que no están guardados y después del add se muestran los que se han añadido al siguiente commit.
