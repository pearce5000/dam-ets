# Unidad 01 - Desarrollo de software y metodologías

## Descripción
Reconocer el ciclo de vida del software y comparar metodologías de desarrollo.

## Objetivos
- Comprender los conceptos fundamentales de esta unidad.
- Identificar técnicas y herramientas aplicables al desarrollo de software.
- Documentar actividades y ejercicios de la asignatura.

## Contenidos
1. Concepto de software y fases del ciclo de vida.
2. Modelos en cascada, iterativo e incremental.
3. Metodologías ágiles: Scrum y Kanban.
4. Requisitos funcionales y no funcionales.
5. Roles, tareas y entregables de un equipo.

## Actividad de la unidad
Elegir una metodología para desarrollar una aplicación de biblioteca.

## Conceptos clave
- Diferencia entre ciclo de vida y metodología.
- Ventajas y límites del modelo en cascada.
- Iteraciones, backlog y entregas incrementales.

## Ejercicios de práctica
1. Redactar tres requisitos funcionales y dos no funcionales para una aplicación de biblioteca.
2. Comparar en una tabla cascada, Scrum y Kanban.
3. Proponer un backlog inicial de cinco tareas ordenadas por prioridad.

## Revisión desde GitHub
La metodología elegida influye en la planificación, la colaboración y las entregas.
